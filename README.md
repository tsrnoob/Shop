# Garching Snack Shop

Chinese snacks and self-heating hot pot, handed over on the TUM Garching campus. Pay on pickup.

- `site/`: the website (shop at `/`, owner page at `/owner.html`), served by Cloudflare Workers via `wrangler.jsonc`
- `supabase/`: database setup (already applied to the Supabase project)
- `SETUP.md`: setup and daily-use guide

Pushing to `main` redeploys the site automatically.
